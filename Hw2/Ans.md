# 求解遞迴方程式

以下為四個遞迴方程式在 $T(1) = 1$ 基底條件下的精確解與漸近複雜度比較表：

| 遞迴關係式 | 邊界條件 | 精確解 (Closed Form) | 複雜度 (Big $O$) | 典型應用 / 代表場景 |
| :--- | :---: | :--- | :---: | :--- |
| **$T(n) = T(n-1) + 8$** | $T(1) = 1$ | $T(n) = 8n - 7$ | **$O(n)$** | 單層迴圈、線性串列走訪 |
| **$T(n) = 2T(n-1) + 9$** | $T(1) = 1$ | $T(n) = 5 \times 2^n - 9$ | **$O(2^n)$** | 未剪枝的二元遞迴樹 (如河內塔) |
| **$T(n) = 2T(n/2) + 1$** | $T(1) = 1$ | $T(n) = 2n - 1$ | **$O(n)$** | 走訪完整二元樹節點、分治尋找極值 |
| **$T(n) = T(n/2) + 1$** | $T(1) = 1$ | $T(n) = \log_2 n + 1$ | **$O(\log n)$** | 二分搜尋法 (Binary Search) |
