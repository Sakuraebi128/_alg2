# 旅行推銷員問題 (TSP) 多演算法比較與實作筆記

本專案使用 Python 針對經典 NP-Hard 問題——**旅行推銷員問題（TSP）**，實作了三種不同層次的解法，並比對其理論極限與工程實用性。

---

### 一、演算法對照與核心機制

| 演算法 | 策略類型 | 時間複雜度 | 優點 | 缺點 / 局限 |
| :--- | :--- | :---: | :--- | :--- |
| **暴力列舉法 (Brute Force)** | 全局精確解 | $O(n!)$ | **保證絕對全局最優**，適合作為小規模基準測試（Ground Truth）。 | 面臨階乘級爆炸；當 $n > 12$ 時計算時間便無法承受。 |
| **最近鄰居貪婪法 (Nearest Neighbor)** | 構造啟發式 | $O(n^2)$ | 邏輯直觀、**計算極快**（微秒級完成），可即時產出初始解。 | 容易陷入局部最優，往往在路徑結尾留下長距離回程線，造成嚴重「交叉」。 |
| **2-Opt 局部搜尋 (2-Opt Local Search)** | 改善啟發式 | 典型 $O(n^2) \sim O(n^3)$ | **有效消除自相交邊**，以極低時間成本顯著逼近最優解。 | 依賴良好初始解，且可能陷入局部極值（Local Minima）。 |

---

### 二、實作關鍵亮點

1. **2-Opt 交換（Edge Reversal）技巧**  
   程式利用 Python 的切片反轉特性 `path[:i] + path[i:j][::-1] + path[j:]` 實現兩邊交換，直觀且高效地將打結路徑「解開」。
2. **三位一體比較閉環**  
   先以 **貪婪法** 快速構建可行路徑，再以 **2-Opt** 進行迭代修復，最後與 **暴力法** 的理論最佳值進行誤差（Gap%）校驗。
3. **路徑幾何視覺化**  
   內建 `plot_comparison` 自動產生對比圖表，可直觀看出 2-Opt 如何透過解開「交錯邊」降低幾何總成本。

---

### 三、工程結論

面對 NP-Hard 問題，**「貪婪構造初解 + 2-Opt 局部優化」** 是算力與解品質之間極佳的平衡策略。它能用不到千分之一秒的時間，獲得與暴力搜尋誤差僅 2%~5% 以內的優質解，是實際物流規劃與路徑排程的基石方案。
