## 1. 老鼠走迷宮問題 (Maze Routing)

* **檔案名稱**：`maze_bfs.py`
* **求解演算法**：**廣度優先搜尋 (Breadth-First Search, BFS)**

### 核心原理
迷宮在離散網格中每一步的移動成本均等（均為 1）。BFS 透過「先進先出（FIFO）」的佇列機制，以起點為中心逐層向外等距離擴展。配合 `visited` 集合避免走入重複迴圈，保證抵達出口時所走的路徑必定為**步數最少的最短路徑**。

### 狀態空間定義
* **狀態 (State)**：老鼠所在的二維座標 $(r, c)$。
* **動作 (Action)**：向上、下、左、右四個方向的未造訪非障礙物網格移動。
* **路徑還原**：使用父節點字典 `parent[(nr, nc)] = (r, c)` 在找到終點後向後回溯。

## 2. 狼羊甘藍菜過河問題 (Wolf, Goat, and Cabbage)

* **檔案名稱**：`river_crossing_bfs.py`
* **求解演算法**：**狀態空間圖 BFS (State-Space BFS)**

### 核心原理
過河問題本質上是有限離散狀態的圖搜尋。系統必須在滿足所有安全約束的前提下，從初始狀態轉移至目標狀態。使用 BFS 可以在所有可能的渡河步驟中，找出**搬運次數最少（7步完成）**的最佳方案。

### 狀態空間與約束
* **狀態 (State)**：四元組 $(F, W, G, C) \in \{0, 1\}^4$，0 代表左岸、1 代表右岸（依序為農夫、狼、羊、甘藍菜）。
* **合法性約束 (Safety Invariant)**：
  * 若農夫不在場 ($F \ne W$ 且 $F \ne G$)，狼與羊不能同岸 ($W \ne G$)。
  * 若農夫不在場 ($F \ne G$ 且 $F \ne C$)，羊與菜不能同岸 ($G \ne C$)。
* **狀態轉移**：農夫每次必須過河 ($F \to 1 - F$)，可選擇獨自過河或攜帶與他同岸的一件物品。

## 3. 八皇后問題 (8-Queens Problem)

* **檔案名稱**：`n_queens_backtracking.py`
* **求解演算法**：**深度優先搜尋 + 回溯剪枝 (DFS with Backtracking)**

### 核心原理
八皇后問題屬於典型的約束滿足問題（CSP）。若採用暴力列舉 $8^8$ 或 $\binom{64}{8}$ 種擺法會引發組合爆炸。回溯法採用「按欄逐一放置」策略，一旦在第 $k$ 欄發現放置位置與前 $k-1$ 個皇后衝突，便**立即中斷該子樹的深入（剪枝 Pruning）**並退回上一層，大幅縮減搜尋空間。

### 衝突檢測數學技巧 ($O(1)$ 判定)
* **同列衝突**：`row in occupied_rows`
* **主對角線衝突 ($\backslash$)**：同條對角線上的座標滿足 $row - col = \text{常數}$，記錄於 `occupied_diag1`。
* **副對角線衝突 ($/$)**：同條對角線上的座標滿足 $row + col = \text{常數}$，記錄於 `occupied_diag2`。

## 4. NPC 搜尋玩家問題 (Game AI Pathfinding)

* **檔案名稱**：`npc_pathfinding_astar.py`
* **求解演算法**：**$A^*$ 啟發式搜尋演算法 ($A^*$ Search)**

### 核心原理
遊戲中的尋路往往包含多種地形代價（如平地成本為 1、泥沼成本為 3、岩石為障礙物不可通行），單純的 BFS 無法處理非均勻權重，而 Dijkstra 演算法盲目向四周擴展會浪費過多算力。$A^*$ 透過評估函數引導搜尋方向：
$$f(n) = g(n) + h(n)$$
* $g(n)$：從起點到當前節點的真實累積代價。
* $h(n)$：當前節點到玩家位置的曼哈頓啟發式預估距離 $|x - x_{target}| + |y - y_{target}|$。

利用優先權佇列（Min-Heap）每次取出 $f(n)$ 最小的節點展開，保證在最短時間內精確鎖定最佳追擊路徑。

## 5. IC 設計中的電路繞線問題 (VLSI Routing)

* **檔案名稱**：`ic_routing_lee.py`
* **求解演算法**：**李氏迷宮繞線法 (Lee's Algorithm / 3D Wave Propagation)**

### 核心原理
晶片佈局與 PCB 繞線常需要在多個金屬層（如 M1、M2）之間走線。本實作將二維平面擴展為三維空間 $(z, y, x)$：
1. **波前擴展 (Wave Expansion)**：從 Pin A 開始向相鄰網格擴展，若在同層移動代價為平面走線成本（預設 1）；若垂直穿透至相鄰金屬層，則需付出打貫孔（Via）的高額代價（預設 2）。
2. **避障 (Obstacle Avoidance)**：已被其他訊號線佔用或阻擋的網格無法通行。
3. **回溯 (Retrace)**：當波前接觸到 Pin B 時，沿著成本梯度的反方向回溯至 Pin A，形成實體導線路徑。

## 六、五大問題與演算法特性對照表

| 問題 | 推薦演算法 | 狀態空間類型 | 邊權重 | 核心優勢 |
| :--- | :--- | :--- | :--- | :--- |
| **1. 老鼠走迷宮** | **BFS** | 二維離散網格 | 均等權重 (1) | 保證找出步數最少的最短路徑 |
| **2. 狼羊菜過河** | **狀態圖 BFS** | 隱式離散圖 ($2^4$) | 均等權重 (1) | 系統性檢驗邊界條件，求出最少渡河步數 |
| **3. 八皇后問題** | **回溯法 (DFS)** | 樹狀組合空間 ($8^8$) | 無 (約束滿足) | 配合數學特性 $O(1)$ 剪枝，極速排除非法狀態 |
| **4. NPC 尋路** | **$A^*$ 演算法** | 帶權重的二維地形圖 | 非均勻權重 (1, 3, $\infty$) | 結合目標啟發引導，兼顧最佳解與搜尋效率 |
| **5. IC 電路繞線** | **Lee's 3D 演算法** | 多層三維網格 | 異質權重 (走線 vs 貫孔) | 嚴格滿足設計規則，保證晶片接腳間最短互連 |
